# Session 2026-11-01 (2) — écran d'attente néon, miroir et tourner

- **Objectif et preuve** : écran d'attente lisible par les autres sur Discord, puis boutons miroir et tourner, puis un nouvel écran d'attente. Preuve : un ami d'Evan lit le texte sur Discord ; Evan confirme « ça marche » pour miroir/tourner et voit le néon dans Discord.
- **Fait** :
  - Webcam : écran d'attente envoyé à l'endroit (plus de miroir).
  - Bouton « Tourner » (90° par clic) à côté du miroir, appliqué par l'iPhone ; `.ipa` reconstruit et installé.
  - iPhone : chien de garde, liaison muette coupée après 15 s sans Ping puis reconnexion immédiate.
  - Maquettes (canevas claude.ai) : 10 pistes d'écran d'attente ; Evan choisit J (néon), sans texte en bas, barre blanche avec des paquets dans les deux sens.
  - Écran néon codé dans l'app (CSS en unités `cqh`) et dans la webcam (Direct2D), 18 langues lettre par lettre.
  - Installation de la webcam : arrêt du service caméra de Windows à la fin.
  - 5 commits poussés.
- **Pas fait** : relancer le service caméra au lancement (demande d'Evan en fin de session) ; Drop.
- **Décisions** : [[ADR-0024 Ecran d'attente a l'endroit dans la webcam]], [[ADR-0025 Tourner applique par l'iPhone]], [[ADR-0026 Recharger le service camera de Windows]] (propose).
- **Problèmes rencontrés** :
  - Bouton miroir « absent » : Evan lançait un vieil exe `release` compilé avant le bouton.
  - `npm run build` bloqué tant que l'ancienne Hyphn tournait dans la zone de notification ; Claude n'a pas pu la fermer (refus du contrôle automatique).
  - Discord gardait l'ancien écran : le service Frame Server garde la DLL chargée. Evan l'a arrêté dans `services.msc`.
  - Copie vers `try/ios` : `rm` refusé sur les fichiers de build créés par Docker (root).
  - Port 8765 déjà pris par une autre app d'Evan.
- **Appris** :
  - Discord ne retourne que l'aperçu de l'utilisateur : ce qui est lisible chez les autres est à l'envers chez soi.
  - Evan veut des maquettes de niveau studio qui gardent le style de l'app ; les pistes trop éloignées (rétro, papier) ne lui plaisent pas.
- **Non vérifié** : reconnexion en moins de 20 s ; arrêt automatique du service après une mise à jour ; texte de l'écran d'attente dans la fenêtre Hyphn (absent sur une capture d'Evan).
