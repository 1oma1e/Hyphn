Preuve : Evan a scanné le QR, relié, streamé, vu « Hyphn » dans Discord et confirmé « ça tient » après un changement d'app ; `cargo test` → 54 OK.
- **Fait** :
  - PC : TLS 1.3 épinglé, `protocol/hyphn.proto`, Bonjour, reconnexion, infos iPhone, simulation retirée ; vidéo par WebSocket local ; « Afficher » synchronisé ; `KeyRequest` ; « Reconnecter ».
  - iPhone : app complète (scan, code, Accueil, Cam, Réglages, Drop vide), logo du PC, QR court, étapes + « Annuler », débit adaptatif, réglages caméra, miroir, liaison gardée en arrière-plan.
  - Webcam Windows (DLL C++ Media Foundation, d'après VCamSample) et plugin OBS, installés tout seuls ; écran d'attente animé (Direct2D, Geist) envoyé en miroir.
  - Relecture par le sous-agent `reviewer` : 25 points (sécurité, boucle à 100 %, débordement possible…), corrigés.
  - 11 commits poussés, `.ipa` et installateur construits.
- **Pas fait** : Drop ; mesures des portes ; maquettes texte ; notification batterie faible.
- **Décisions** : [[ADR-0020 Phase 1 sans attendre le rafraichissement]], [[ADR-0021 Plus de module Pulse]], [[ADR-0022 Webcam Windows par DLL qui decode]], [[ADR-0023 Connexion gardee et reconnexion facile]].
- **Problèmes rencontrés** :
  - « Afficher » se remettait en pause : les deux apps se renvoyaient leur état → seul un vrai appui sur l'iPhone compte (`by_user`).
  - Gels : décodeur vidé à chaque rafale Wi-Fi + image clé toutes les 2 s → dernière image seulement, image clé à la demande.
  - Installation de la webcam : empreinte changeante (MSVC met la date → `/Brepro`), puis PowerShell admin qui plantait → l'app se relance elle-même en admin (Rust).
  - Le service caméra de Windows n'a pas le décodeur HEVC (extension du Store, par utilisateur) → H.264 forcé quand la webcam sert.
  - Webcam à 21 images/s : attente Windows précise à 15,6 ms → minuteur haute résolution, 30 images/s.
- **Appris** :
  - La DLL de webcam tourne dans le service Frame Server (Local Service) : dossier lisible par le service, classe COM dans HKLM, pas de partage de mémoire simple → tuyau nommé.
  - Discord retourne seulement l'aperçu de l'utilisateur ; les autres voient l'image normale.
  - iOS coupe la caméra hors de l'app et laisse ~30 s de réseau en arrière-plan.
- **Non vérifié** : OBS ; installateur lancé pour de vrai ; correction du zoom HEVC ; coût batterie et CPU ; 1 h de stream.
