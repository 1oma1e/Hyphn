- **Décisions** : [[ADR-0040 Mises a jour auto et depot public]], [[ADR-0041 Licence PolyForm Strict]].
- **Problèmes rencontrés** :
  - Le dépôt était privé : l'API GitHub répondait 404, une Release n'aurait servi à personne.
  - Mozilla liste le russe 3.0 pour PC sans fichier de vocabulaire : le choix « le plus récent de chaque type » mélangeait aussi les versions. On prend désormais un lot complet d'une seule version, PC d'abord, sinon Android.
  - L'interrupteur `.sw` était un `span` en ligne : sans taille, seul le rond s'affichait.
  - Python dans un heredoc a transformé `\v` en tabulation verticale dans STATE ; PowerShell 5.1 écrit un JSON illisible (d'où `tidy_json.py`).
- **Appris** :
  - Le compte Apple gratuit suffit (pas de programme développeur) ; mode développeur obligatoire sur l'iPhone.
  - L'updater Tauri ne marche qu'à partir d'une version qui l'embarque : la 0.1.1 passe à la main.
- **Non vérifié** : mise à jour réelle PC et SideStore (il faut une Release publique) ; libellés exacts de SideStore et des Raccourcis ; traduction russe et texte réduit dans la vraie app et Discord ; aperçu déplaçable dans la vraie app ; automatisation du rafraîchissement.
