# Session 2026-10-31 — Phase 0 : Hello SwiftUI avec xtool

Commencée le 2026-10-30 au soir.

- **Objectif et preuve** : un « Hello » SwiftUI construit par xtool sur le serveur, installé par SideStore. Preuve : l'app ouverte sur l'iPhone (confirmé par Evan, sans capture).
- **Fait** :
  - Source xtool 1.24.0 lue : l'anisette `mac-ani.jkcoxson.com` est codée en dur, l'identité de l'appareil vient du même serveur. `xtool ds anisette` OK sur le serveur (identité « Mac OS X 10.12.6 »).
  - `xtool setup` par Evan avec l'Apple ID secondaire : connecté, jeton valable 1 an, SDK reconnu.
  - `apps/ios/` : modèle exact de `xtool new` 1.24.0, bundle ID `io.github.1oma1e.hyphn`, texte « Hello, Hyphn! ». Commit `74f86a5`, 6 commits poussés.
  - Serveur : clé de déploiement lecture seule, clone dans `~/hyphn/xtool/src`, `xtool dev build` OK, `.ipa` (13 Ko) zippé en Python, copié dans `F:\Hyphn\out`. Evan l'a passé sur l'iPhone et installé avec SideStore : « Hello, Hyphn! » s'affiche.
  - Raccourci `Refresh SideStore` : Set VPN Connect LocalDevVPN → Wait 3 s → Refresh All Apps → Wait 30 s → Set VPN Disconnect. Test à la main OK (confirmé par Evan). Automatisation Time of Day, lundi et jeudi à 20 h, Run Immediately.
- **Pas fait** : plan B AltServer-Linux + netmuxd ; premier rafraîchissement par l'automatisation (lundi 2026-11-02).
- **Décisions** : [[ADR-0013 Build iOS par clone Git]] (clone + clé lecture seule, bundle ID, zip Python) ; automatisation 2 fois par semaine plutôt que chaque jour (choix d'Evan, au plus 4 jours entre deux rafraîchissements).
- **Problèmes rencontrés** :
  - `-22406` : mot de passe mal tapé au premier essai.
  - Aucun code 2FA : Apple a choisi la notification « appareil de confiance », et aucun appareil n'était connecté au compte secondaire. Contournement xtool-org/xtool#368 : compte ajouté dans Mail sur l'iPhone, connexion sur account.apple.com, code de l'iPhone recopié dans xtool.
  - Premier build : `swift-package` plante (signal 11) ; les essais suivants passent. Cause inconnue.
  - `xtool dev build --ipa` : `zip` absent de l'image, et le `.app` est effacé. Contournement : build sans `--ipa`, puis `python3 -m zipfile`.
  - Repo privé : 404 sans connexion, d'où la clé de déploiement. Premier ajout de la clé sur GitHub pas enregistré (`Permission denied`), refait.
  - `http.server` sur le serveur injoignable depuis le PC (pare-feu du serveur, non touché) : `.ipa` copié par `scp`, puis passé sur l'iPhone par Evan.
- **Appris** :
  - SideStore « Refresh All Apps » : au-delà de 27 s, l'action demande à passer au premier plan et rend la main avant la fin (d'où le Wait 30 s avant de couper le VPN).
  - Une app expirée reste installée avec ses données ; un Refresh la relance. SideStore expire aussi : s'il expire, il faut iloader sur le PC.
  - Le téléphone d'Evan est en anglais : donner les libellés iOS en anglais.
- **Non vérifié** : automatisation téléphone verrouillé ; plantage `swift-package` ; expiration à J+7 ; liste d'actions de LocalDevVPN (source officielle introuvable, l'action iOS « Set VPN » suffit).
