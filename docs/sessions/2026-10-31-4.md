# Session 2026-10-31 (4) — App PC complète, iPhone simulé

- **Objectif et preuve** : coder toute l'app PC (Tauri) au design V2, le scan du QR étant simulé. Preuve : `cargo test` vert (27 tests) et parcours capturé sur la vraie fenêtre : QR → « Simuler le scan » → code → « Oui, relier » → « liés » (≈ 8 s) → Accueil avec la bulle. Atteint, commit `c34222f`.
- **Fait** :
  - `apps/desktop/` : Rust + Tauri 2, interface en HTML/CSS/JS sans framework, polices Geist en local (aucune requête internet).
  - Réel : identité et certificat du PC (E1), QR `hyphn://pair?` avec IP locale, port 47800 et jeton 128 bits de 2 min à usage unique (E2, E3), code à 4 chiffres tiré des empreintes (E6), appareil gardé jusqu'à « Oublier » (E7, E10), réglages en JSON, règle thermique de Cam (RULES, Énergie 9), lecture des dossiers année/mois de Drop.
  - Simulé dans `demo.rs` : l'iPhone (scan, batterie, chaleur, stockage, stats Cam, transferts). Pastille « démo » partout ; carte « iPhone simulé » dans les Réglages pour mettre l'iPhone en veille, chaud ou à 12 %.
  - Vérifié en capture : Accueil (relié, en veille, aucun), Appairage, Cam (pause, direct, tiroir, alerte « très chaud » → 1080p30), Drop (réception, coupure, reprise, fin + historique), Réglages, thème clair, bandeau batterie faible.
- **Pas fait** : TLS (E4), `PairRequest` en Protobuf (E5), Bonjour, vérifications réseau E11 (seul « pas de réseau local » est géré), notification Windows de batterie faible, webcam virtuelle et plugin OBS.
- **Décisions** : [[ADR-0019 App PC en premier avec iPhone simule]] (choix d'Evan, accepté).
- **Problèmes rencontrés** :
  - Pas d'outil de capture du bureau dans la session. Contournement : port de débogage WebView2 (`additionalBrowserArgs` dans une config de dev hors du repo) + petit script Node (CDP) pour cliquer et capturer.
  - La variable `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` est ignorée : Tauri impose ses propres arguments.
  - Tauri ajoute un nonce à la CSP, qui annule `'unsafe-inline'` des styles : `dangerousDisableAssetCspModification: ["style-src"]`.
  - QR avec des lignes blanches entre les modules : `shape-rendering: crispEdges`.
  - `CARGO_TARGET_DIR` global vaut `F:\safesweep-target` : le build Hyphn y va aussi (partagé avec SafeSweep).
- **Appris** : Evan a lui-même relié l'iPhone simulé dès le premier lancement ; le parcours lui parle sans explication.
- **Non vérifié** : icône près de l'horloge et fermeture vers elle, « Lancer avec Windows » (registre), fenêtres de choix de dossier et de fichiers, glisser-déposer depuis l'Explorateur, « Ouvrir le dossier », build `npm run build` (installateur NSIS).
