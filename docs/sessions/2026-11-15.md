# Session 2026-11-15 — vraie app Windows et webcam pendant un jeu

- **Objectif et preuve** : une vraie app installée par un setup, qui garde réglages et langues ; une webcam qui ne passe plus à l'écran d'attente pendant un jeu. Preuve : setup installé et relancé sans re-téléchargement ; Discord sans écran d'attente pendant un jeu.
- **Fait** :
  - Setup NSIS (option A, construit sur le PC, [[ADR-0039 Setup Windows publie sur GitHub]]) : 0.1.0 puis 0.1.1, installé par Evan dans `E:\Hyphn`, raccourci sur le bureau.
  - Langues : on garde les modèles déjà sur le disque même si Mozilla en publie de plus récents ; la liste des modèles connus est fusionnée ; plus de boucle quand une langue n'existe pas en bureau. Suppression d'une langue décochée confirmée par Evan (« Espace libéré 36 Mo »).
  - Webcam : la cause de l'écran d'attente est un trou de 0,5 à 1 s dans les images (vu dans `vcam.log`) quand le PC est pris par un jeu. Correctifs : 10 s de dernière image gardée si l'iPhone est relié, refus d'EcoQoS, priorité haute au décodage, fenêtre non ralentie en arrière-plan, trous notés dans le journal.
  - `cargo test` : 102 passent. 2 commits poussés sur GitHub.
- **Pas fait** : Release GitHub v0.1.1 (à faire par Evan) ; journaux des sessions du 2026-11-03 au 05.
- **Décisions** : [[ADR-0039 Setup Windows publie sur GitHub]] (accepté, option A, Release envoyée à la main) ; E4 de [[Cam - Webcam Windows et OBS]] complété.
- **Problèmes rencontrés** :
  - Claude lisait une copie privée d'AppData (paquet MSIX de Claude) et en a tiré une fausse conclusion (« réglages non sauvés »). Les vrais fichiers, lus par `\\localhost\C$`, étaient à jour.
  - Hyphn lancé depuis Claude démarre caché et utilise une autre identité.
  - Le dossier des langues et l'identité ont été effacés à 17:13 : sans doute la désinstallation de 0.1.0 avec effacement des données (non vérifié).
  - Le raccourci du bureau visait l'ancien chemin `C:\Program Files` après le déplacement vers `E:`.
- **Appris** : pour vérifier ce que voit Evan, lire ses fichiers par le partage admin, jamais par le chemin AppData normal ; Discord change d'image dès 1,5 s de trou, donc un jeu suffit à le déclencher.
- **Non vérifié** : Discord pendant un jeu avec 0.1.1 ; traduction du message dans la webcam ; cause de l'effacement de 17:13.
