# iPhone — Cam

Les réglages fins se font sur [[PC - Cam]]. L'iPhone n'a que le minimum, pour économiser l'écran et la batterie.

## Avant le stream
```
┌──────────────────────────────┐
│ ‹ Retour          Cam        │
│ ┌──────────────────────────┐ │
│ │      (aperçu caméra)     │ │
│ └──────────────────────────┘ │
│ Objectif  [0,5×] [1×] [3×]   │
│ Qualité   [Auto ▾] 1080p30   │
│ Micro     [ off ]            │
│                              │
│ ┌────────────────────────┐   │
│ │     Démarrer le flux   │   │
│ └────────────────────────┘   │
│ Conseil : retire la coque,   │
│ charge par câble.            │
└──────────────────────────────┘
```

## Pendant le stream (écran noir)
L'aperçu est coupé, la luminosité est au minimum, l'app reste au premier plan (iOS coupe la caméra en arrière-plan).
```
┌──────────────────────────────┐
│                              │
│                              │
│           ● EN DIRECT        │
│        4K30 · 32 Mb/s        │
│                              │
│   Touche deux fois pour      │
│   afficher les commandes     │
│                              │
│                              │
└──────────────────────────────┘
```
Double-touche → commandes par-dessus le noir : `Pause` · `Arrêter` · `Objectif` · `Lampe`.

## États
| État | Ce qui change |
|---|---|
| Chauffe « serious » | Ligne « Chaud : 30 fps » sous EN DIRECT ; le PC l'affiche aussi |
| Chauffe « critical » | « Très chaud : 1080p30 » ; alerte sur le PC |
| Batterie < 15 % sans charge | « Batterie faible : qualité réduite » |
| Connexion perdue | « Reconnexion… » ; le flux reprend seul quand le Wi-Fi revient |
| Appel ou autre app au premier plan | Le flux s'arrête ; message sur le PC « Caméra de l'iPhone interrompue » |
